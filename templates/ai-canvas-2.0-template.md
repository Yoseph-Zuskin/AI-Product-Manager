# AI Canvas 2.0 Template

Use this template to frame AI initiatives using the AI Canvas 2.0 framework from the AI Strategies for Business Transformations program.

## Narrative Format (10 Questions)

Answer each question concisely. This format tells the story of your AI initiative.

| # | Question | Your Answer |
| --- | --- | --- |
| 1 | **The business problem** we plan to address | |
| 2 | **Why** this problem is important | |
| 3 | **How** an AI-based solution will address the problem | |
| 4 | **Key benefits** to the business and customers | |
| 5 | **Quick financial impact** estimate (e.g., $X cost savings or revenue) | |
| 6 | **Cross-functional team** composition needed | |
| 7 | **Necessary resources** (headcount, budget, data, compute) | |
| 8 | **90-day proof-of-concept** plan | |
| 9 | **Hurdles/risks** that will be faced | |
| 10 | **Plan to mitigate risks** | |

## Blueprint Format (9 Cells Across 3 Phases)

### Phase 1: Define (Frame It)

| Cell | Focus | Your Input |
| --- | --- | --- |
| **Business & Customer Problem** | What specific business/customer problem are we solving? | |
| **Jobs to Be Done (JTBD)** | What job is the customer/process hiring a solution to do? | |
| **Business Impact** | Revenue enhancement, cost reduction, risk mitigation, productivity improvement? Quantify. | |

### Phase 2: Design (Bottle It)

| Cell | Focus | Your Input |
| --- | --- | --- |
| **Data & Model Management** | Data sources, cleaning, labeling, access control. Fine-tuning vs. custom model? | |
| **Context & Fine-Tuning** | Prompts, RAG, proprietary data, human-in-the-loop design | |
| **MVP & Rapid Prototyping** | Lean AI MVP in agile sprints, 90-day pilot scope | |

### Phase 3: Deploy (Scale It)

| Cell | Focus | Your Input |
| --- | --- | --- |
| **Testing & Scaling** | Productionizing, integrating with systems of record/insight/engagement | |
| **Implementation & Change Management** | Adoption strategies, workflow integration, resistance management | |
| **Governance & Risk Mitigation** | | |
