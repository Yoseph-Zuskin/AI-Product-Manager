## V2MOM Framework Overview

## AI Product Manager Adaptation

For AI products, extend V2MOM with:

### ML-Specific Vision

- What does "AI-powered" mean for your product in 3-5 years?
- What ML capabilities will be core vs. commodity?

### AI-Specific Values

- **Responsible AI** — Fairness, transparency, privacy by design
- **Data-Driven Decisions** — Evidence over intuition
- **Human-in-the-Loop** — AI augments, doesn't replace judgment

### AI-Specific Methods

| Method | Purpose | Tool/Framework |
| --- | --- | --- |
| Frame AI initiatives | AI Canvas 2.0 | [AI Canvas 2.0](../references/ai-canvas-2.0.md) |
| Map enterprise opportunities | AI Radar 2.0 | [AI Radar 2.0](../references/ai-radar-2.0.md) |
| Assess org readiness | AI Capability Maturity Model | [AI CMM](../references/ai-capability-maturity-model.md) |
| Frame opportunities | JTBD Framework | [JTBD/RWW](../references/jtbd-rww-frameworks.md) |
| Assess org readiness | AI Capability Maturity Model | [AI CMM](../references/ai-capability-maturity-model.md) |

### AI-Specific Obstacles

| Obstacle | Mitigation |
| --- | --- |
| Data quality/availability | Invest in data infrastructure, feature store |
| Model drift/performance decay | Automated monitoring, retraining pipelines |
| Talent scarcity | Upskilling, platform investment, partnerships |
| Regulatory uncertainty | Privacy by design, model cards, audit trails |

### AI-Specific Measures

| Measure | Target | Current | Frequency |
| --- | --- | --- | --- |
| Model accuracy/F1 | > X% | | Weekly |
| Inference latency (p99) | < X ms | | Real-time |
| Model drift detection | < X alerts/month | | Daily |
| Fairness (demographic parity) | < X% gap | | Weekly |
| Inference cost per 1K | < $X | | Daily |
| Model retraining frequency | Monthly | | Monthly |

### Execution Cadence

| Cadence | Participants | Purpose |
| --- | --- | --- |
| Weekly | PM + Tech Lead | Sprint alignment, blockers |
| Monthly | PM + Tech Lead + Stakeholders | Progress vs. measures, obstacle review |
| Quarterly | Full team + Leadership | Vision check, obstacle triage, measure reset |
| Annually | Full team + Leadership | Vision check, obstacle triage, measure reset |
