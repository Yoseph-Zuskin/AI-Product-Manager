# Jobs-To-Be-Done (JTBD) & Real-Win-Worth (RWW) Frameworks

Customer-centric opportunity discovery frameworks used across both Kellogg Executive Education programs.

## Jobs-To-Be-Done (JTBD)

**Definition**: The job a customer or process wants done — not the product. Serves as the unit around which AI opportunities and use cases are organized, prioritized, and built.

### JTBD Statement Format

`As a [persona], when [situation], I want to [goal] so I can [outcome]`

### Three Types of JTBD

- **Functional** — The task the customer wants to get done
- **Emotional** — How the customer wants to feel
- **Social** — How the customer wants to be perceived by others

### Application in Both Programs

- **AI Strategies**: Uses JTBD enterprise-wide as organizing framework for AI value creation (customer management, operations, support functions)
- **AI-Driven Product Strategy**: Uses JTBD to find and prioritize product opportunities (customers "hire" products to get a job done)

## Real-Win-Worth (RWW) Model

**Definition**: Market opportunity assessment framework evaluating opportunities on three criteria:

| Criterion | Description |
| --- | --- |
| **Real** | The problem actually exists in the market |
| **Worth** | Customers value solving this problem |
| **Win** | We can win this opportunity |

- Module 2 (Opportunity Analysis and Product Discovery) uses RWW to assess product opportunities
- Combines with JTBD to structure opportunity briefs
- Helps prioritize high-opportunity jobs as those that customers consider important, where the current best solution is unsatisfying, and where many customers want the job done
